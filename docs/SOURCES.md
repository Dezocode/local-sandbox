The supplied guide's particular model names were not treated as evidence of current availability. Provider app actions must be confirmed against the version installed on the phone. App subscription access is not a model API credential. Local Sandbox validates only a user- or Shortcut-returned response against its local challenge and assertions. The Record Provider Check intent records that returned text reached that App Intent. It cannot prove unattended end-to-end execution, the response's app or provider origin, the provider account, the active model, or the personal Shortcut's contents. Those claims require live visual evidence on the physical device. The app makes no vendor benchmark claims. Every task route, including direct Apple Intelligence, requires all five completed probe types, at least 80% schema-validation and assertion-pass rates, zero integrity faults, all required tool probes, and enough tested context. External Siri routes also require an observed App Intent return for every probe. Manual-return routes are never eligible for unattended Siri.
