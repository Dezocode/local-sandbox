Storage & privacy

On-device encrypted vault. No file content or password is sent to a server. This vault is independent of the online dashboard.

Shortcuts dependencies

Install the native Xcode app for Prepare Workspace, Begin Oracle Task and Apply Reviewed Action. Third-party app workflows must be saved in Shortcuts before running.

The test only opens the named workflow. Verify its returned text in Shortcuts; this page cannot inspect installed workflows.

Home Screen & updates

In Safari, tap Share → Add to Home Screen → Open as Web App. Open this workspace once online to prepare the offline shell. Local data is never removed by an app update.
